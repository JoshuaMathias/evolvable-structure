# Documentation

ESOI is mainly explanation and templates. The Python package is one way to check and measure what you write; nothing
here requires it.

| Folder | Read it when |
|---|---|
| [explanation/](explanation/) | You want to know what ESOI is and why it is shaped this way |
| [templates/](templates/) | You are about to write an intent record, an overall network, a standard or a review sheet |
| [guides/](guides/) | You want to apply ESOI to a project, by hand first and then with tools |

Also worth knowing early: [when metrics are run](explanation/when-metrics-are-run.md) says when to run each metric and who
approves the spend, and [its template](templates/metric-run-policy.md) is how a repository records its own policy.

The author's own words, the definitions, principles and the intent template, are quoted from the evolvable-structure
skill's `SKILL.md` and regenerated whenever it changes: see
[explanation/from-the-skill.md](explanation/from-the-skill.md) and [templates/](templates/). The files in those
two places are generated; to change a question, change `SKILL.md`, then run `esoi template sync`.
